1. what is system design 


#System Design = Blueprint of a System

System design is the process of planning and defining the architecture, components, and interactions of a software system to meet specific requirements — such as performance, scalability, reliability, and maintainability.

⚙️ Key Goals of System Design
Scalability – Can it handle more users and data as it grows?
Reliability – Does it keep working even if some parts fail?
Performance – Is it fast and responsive?
Maintainability – Is it easy to update or fix later?
Security – Is user data safe and protected?
Extensibility – Can we easily add new features in the future?
